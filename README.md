# 3D CSS Slider

A rotating 3D image carousel made only with CSS transforms and animation.

## Features

- Images arranged in a ring with `transform-style: preserve-3d`
- Continuous rotation with keyframe animation
- No JavaScript

## Run it

No build step. Open `index.html` in a browser, or serve the folder with any static server, for example `python -m http.server`.
